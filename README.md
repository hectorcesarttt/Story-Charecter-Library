# Story-Charecter-Library

Story Character Visual Reference Library

Purpose

This repository contains the official visual reference artwork for characters in the story. It serves as the central visual reference database for maintaining consistent character appearances throughout story interactions and AI-generated artwork.

Instructions for AI

* Use this repository as the central source for character visual references.
* Consult the individual character folders and their README files.
* Use direct image URLs when referencing specific artwork.
* Preserve established character designs, facial features, hairstyles, colors, proportions, and clothing.
* Select the appropriate expression, outfit, or alternate form for the current scene.
* Never confuse one character’s appearance with another’s.
* Treat these images as visual canon.
* Do not invent conflicting visual characteristics.
* If an exact reference is unavailable, use the closest available reference while preserving established character descriptions.
* These instructions apply to all existing and future characters.

Reference Categories

Individual character folders may contain:

* Appearance and physical features
* Facial expressions and emotions
* Casual clothing and formal outfits
* Combat clothing and equipment
* Alternate forms and transformations
* Injuries and physical conditions
* Special poses and character-specific states

Visual Consistency Rules

1. Character identity must remain consistent across all images.
2. Expressions may change, but permanent physical characteristics should not.
3. Alternate forms must remain visually distinct.
4. Clothing should match the current story context.
5. Reference images take priority over generic visual assumptions.

Maintenance

New characters and images should be added to their appropriate folders. Each character’s README should be updated with descriptive labels and direct image URLs.

This repository is an evolving visual reference library. All additions should preserve organization and consistency.
